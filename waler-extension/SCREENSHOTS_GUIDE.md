# 📸 Guide de Création des Screenshots

Pour publier l'extension, vous devez créer 3 à 5 screenshots de qualité.

## 📐 Spécifications Techniques

### Chrome Web Store & Edge Add-ons
- **Taille recommandée** : 1280x800 pixels (ratio 16:10)
- **Taille alternative** : 640x400 pixels
- **Format** : PNG ou JPEG
- **Poids max** : 2 MB par image
- **Nombre** : 3 à 5 screenshots

### Firefox Add-ons
- **Taille recommandée** : 1280x800 pixels
- **Format** : PNG ou JPEG
- **Poids max** : 4 MB par image
- **Nombre** : 1 à 10 screenshots

## 🛠️ Outils de Capture Recommandés

### Windows
- **Snipping Tool** (intégré)
  - Win + Shift + S
  - Capturer une zone personnalisée
  
- **ShareX** (gratuit)
  - Capture avec redimensionnement automatique
  - Annotations possibles
  - https://getsharex.com/

- **Greenshot** (gratuit)
  - Capture et édition rapide
  - https://getgreenshot.org/

### Extensions Chrome
- **Awesome Screenshot**
  - Capture de page complète
  - Annotations intégrées
  
- **Nimbus Screenshot**
  - Capture et édition
  - Export direct

## 🎨 Conseils de Design

### Qualité
- ✅ Haute résolution (pas de flou)
- ✅ Couleurs vives et contrastées
- ✅ Interface propre (pas de données personnelles)
- ✅ Texte lisible
- ❌ Pas de watermarks
- ❌ Pas de contenu offensant

### Composition
- Centrer les éléments importants
- Laisser de l'espace autour des éléments clés
- Utiliser des données de test réalistes mais anonymes
- Montrer l'extension EN ACTION (pas juste des menus)

### Cohérence
- Même thème de couleurs sur tous les screenshots
- Même style d'interface
- Même niveau de zoom/taille de police

## 🔄 Workflow de Création

1. **Préparer les données de test**
   - Créer un compte de test
   - Générer des statistiques fictives
   - Remplir le dashboard avec des données réalistes

2. **Capturer les screenshots**
   - Utiliser un outil de capture
   - Respecter la taille 1280x800
   - Capturer en PNG pour la qualité

3. **Éditer si nécessaire**
   - Flouter les données personnelles
   - Ajouter des annotations (optionnel)
   - Optimiser la taille du fichier

4. **Valider**
   - Vérifier la taille (1280x800)
   - Vérifier le poids (< 2 MB)
   - Vérifier la qualité (pas de flou)

5. **Organiser**
   - Nommer les fichiers : `screenshot-1-dashboard.png`, etc.
   - Créer un dossier `screenshots/`
   - Préparer les descriptions
