# Politique de Confidentialité - Waler Extension

**Dernière mise à jour : 28 juin 2026**

## Introduction

Waler ("nous", "notre") respecte votre vie privée. Cette politique explique comment notre extension Chrome/Firefox collecte, utilise et protège vos données.

## Données Collectées

### 1. Données Instagram
- **Nombre de followers/unfollowers** : Collecté automatiquement depuis votre profil Instagram
- **Liste de followers** : Noms d'utilisateur uniquement (pas de données personnelles)
- **Statistiques d'engagement** : Likes, commentaires, partages sur vos publications
- **Profils visités** : Noms d'utilisateur des profils que vous consultez

### 2. Données d'Authentification
- **Token d'authentification** : Stocké localement pour synchroniser avec votre compte Waler
- **Cookies Instagram** : Utilisés uniquement pour accéder aux API Instagram en votre nom

### 3. Données Techniques
- **ID d'extension** : Pour identifier votre installation
- **Logs d'erreurs** : Pour améliorer la stabilité de l'extension

## Comment Nous Utilisons Vos Données

### Finalités
1. **Tracking de followers** : Détecter les nouveaux followers et unfollowers
2. **Analytics** : Générer des statistiques sur votre compte Instagram
3. **Synchronisation** : Sauvegarder vos données sur nos serveurs sécurisés
4. **Amélioration du service** : Corriger les bugs et ajouter des fonctionnalités

### Traitement
- Toutes les données sont **chiffrées** avant transmission
- Stockage local sur votre appareil via Chrome Storage API
- Synchronisation optionnelle avec nos serveurs (waler.website)

## Partage de Données

**Nous ne vendons JAMAIS vos données.**

Partage limité à :
- **Nos serveurs** : Pour la synchronisation et le backup
- **Aucun tiers** : Vos données ne sont jamais partagées avec des entreprises tierces

## Stockage et Sécurité

### Stockage Local
- Données stockées dans Chrome/Firefox Storage (chiffré par le navigateur)
- Accessible uniquement par l'extension

### Stockage Serveur
- Hébergé sur des serveurs sécurisés (HTTPS uniquement)
- Base de données chiffrée
- Backups réguliers

### Mesures de Sécurité
- ✅ Authentification JWT
- ✅ HTTPS obligatoire
- ✅ Pas de stockage de mots de passe
- ✅ Chiffrement des données sensibles

## Vos Droits (RGPD)

Vous avez le droit de :
1. **Accéder** à vos données : Contactez-nous pour obtenir une copie
2. **Rectifier** vos données : Modifiez-les depuis votre dashboard Waler
3. **Supprimer** vos données : Désinstallez l'extension et supprimez votre compte
4. **Exporter** vos données : Téléchargez vos statistiques en JSON/CSV
5. **Vous opposer** au traitement : Désactivez la synchronisation

## Cookies et Permissions

### Permissions Requises
- `storage` : Sauvegarder vos préférences localement
- `cookies` : Accéder aux cookies Instagram pour l'authentification
- `webRequest` : Intercepter les requêtes Instagram pour collecter les données
- `notifications` : Vous alerter des nouveaux unfollowers
- `alarms` : Vérifier périodiquement les changements

### Justification
Chaque permission est **strictement nécessaire** au fonctionnement de l'extension. Nous n'utilisons aucune permission à des fins publicitaires.

## Données Instagram

### Conformité
- Nous respectons les [Conditions d'Utilisation Instagram](https://help.instagram.com/581066165581870)
- Nous n'utilisons **aucune API non-officielle** de manière abusive
- Nous ne collectons que **VOS propres données**

### Limitations
- Nous ne collectons **jamais** les données d'autres utilisateurs sans leur consentement
- Nous ne publions **jamais** en votre nom sans autorisation explicite

## Conservation des Données

- **Données actives** : Conservées tant que vous utilisez l'extension
- **Après désinstallation** : Supprimées sous 30 jours
- **Compte supprimé** : Suppression immédiate de toutes les données

- Email (si vous avez un compte Waler)
- Mise à jour de la date en haut de ce document
